# KiCad Online 0.12.93 / Android 1.95

GitHub preview. Store submissions and approval are separate; existing reviews are unchanged. Android APK is development-signed, not a Google Play release. Altium beta remains separate and excluded.

- Enforce the optional repository comment policy for browser-session posting using a fresh, complete default-branch root and the current website account. A missing policy defaults to signed-in access only when the root listing proves absence. Malformed, unreadable or unverified rows fail closed. Restricted contributor/collaborator rules require positive verification; browser-session owners and explicitly allowlisted reviewers can qualify without a broad repository OAuth account.
- Recover uncertain browser-session publications through a read-only check of the original account, exact body/title and conversation identity. Recovery never sends a second post. Pending receipts retain the original text, account and screenshot metadata across worker restarts. Older receipts without enough evidence require manual inspection.
- Preserve unchanged annotation timestamps for exact publication retries; screenshot-only and conversation-type edits advance the optimistic-concurrency version against an immutable saved baseline.
- Keep each conversation's original source and thread identity after saving multiple drafts, including later edits to those conversations. Release draft image preview resources when saved.

## Verification boundaries

The commenting hardening received independent source review and focused failure-case regressions. The release pipeline runs the complete tagged JavaScript/Python gates, serial offline Android assemble/lint/bundle, package inventories, signature checks and SHA-256 verification before publishing.

Installed-browser acceptance of these new hardening paths remains incomplete: desktop browser control stopped because the active URL could not be verified reliably. Earlier 0.12.92 public KERO checks demonstrated direct text/image replies, automatic website-edit readback and cross-sheet Locate; those results do not establish live acceptance of this newer policy/recovery code. Private/organization SSO, Firefox Android and physical-device acceptance are not implied. This preview is not a guarantee of glitch-free operation.
