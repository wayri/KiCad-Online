# KiCad Online 0.12.92 / Android 1.94

GitHub preview published. Chrome is pending review; VS Code is uploaded and verifying. Android APK is development-signed, not a Google Play release.

- Browse Issues and Discussions in separate comment tabs, with Back, Forward and Home navigation. Float and dock the same conversation panel without losing its draft or refresh owner.
- Support current GitHub Issue forms and native Discussion forms through the invoked repository browser session. Preserve website drafts, confirm the destination/account, retain uncertain-send receipts and prevent automatic duplicate retries. Discussion replies use explicitly labelled quotes; native nested replies and polls are not supported.
- Keep conversation and annotation action menus expanded during refresh. Preview pasted images immediately, show removal controls outside collapsed menus, and preserve drafts on upload failures.
- Accept GitHub’s native dimensioned HTML image markup as well as Markdown after upload, while rejecting changed drafts, mismatched assets/dimensions and unexpected attributes.
- Keep Float/Dock, Pin/Unpin and Collapse controls readable and separate; bound image-draft scrolling so Send remains reachable.
- Read supported location metadata back from Issues and Discussions. Partial website snapshots preserve markers from unseen messages; unknown Discussion states remain neutral.
- Resolve popup companions from the full loaded schematic hierarchy. Apply changed popup selections locally and back to the main drawing. Layout/3D popups have independent layer controls and default to copper, silkscreen and outline.
- Open an explicitly selected pinned project file even when optional parent-folder discovery is unavailable.
- Resolve project/sheet/component variables in properties, retain their provenance, and add a searchable schematic Variables viewer.
- Give Explorer, Properties, Variables, Layers, Probe, Float and Dock distinct semantic icons.
- Wrap each desktop drawing ribbon to its split or detached pane width, keeping sheet and variant selectors within the pane.
- Maximize the interactive floating sheet tree within its drawing pane and restore its compact size without changing the active drawing or camera.
