# KiCad Online 0.12.94 / Android 1.96

GitHub preview. Store submission and approval are separate; existing store reviews remain unchanged. Altium beta is separate and excluded. The Android APK uses the established development signer; this is not a Google Play release.

- Start projects directly in their matching schematic, with a layout fallback for PCB-only projects. Explicit drawing links retain their requested file and repository revision; ambiguous entry sheets remain a user choice.
- Simplify primary navigation to Projects, Schematic, Layout, 3D, BoM, Simulation and History. Keep Project settings, Draftsman and secondary actions in More; use consistent control sizing and a grouped Help panel at the top right.
- Defer initial drawing Fit until hidden panes have a usable viewport, retain 2D zoom/pan across hide/reveal cycles, and reuse the 3D scene across Layout/3D switches to retain its camera and explode setting.
- Preserve saved schematic stroke/fill/text RGBA colours, native fill modes and graphic dash styles, including PCB solid fills and dashed outlines. Use KiCad's standard light schematic colours and body-background fill, with bounded hatch previews. Custom native theme files are not imported; unspecified colours retain the viewer's theme defaults.
- Improve Smart Select using screen-space geometry, clearer electrical-target disambiguation and individual pin, pad, via and saved-object selection. Unfilled drawing rectangles no longer capture clicks throughout their interiors.
- Clicking schematic labels, sheet-pin flags and explicit power symbols highlights their saved connected net. Shift-click selects only the flag or label; ERC power flags remain connectivity markers and do not rename nets.
- Use layer-colored net highlighting with all saved 2D layers visible by default. Add per-layer visibility eyes and keep the layer selector open during interaction.
- Build the native BoM from saved design objects, resolve variables with provenance, and support variants and linked schematic/layout/3D views. Retain optional CSV and HTML imports.
- Preserve 3D net selection while panning: native right-click menu events no longer perform a pick during a drag. Stationary context-menu clicks and ordinary left-click selection remain distinct.
- Identify selected pins and pads by component and terminal (for example U3.1 or U3.A12) in Properties, with persistent terminal details alongside the component fields.
- Add an Explode slider directly to the 3D ribbon. Separate saved copper layers, move component models with their board side and stretch via walls across their saved spans while keeping selected geometry, terminal labels and open 3D probes aligned. Zero restores the assembled view; dielectric material remains centered and spacing is for display only.
- Separate pad/via cap materials from extruded walls, using slope-aware cap depth precedence to address copper striping at shallow viewing angles. Keep walls unbiased and selection overlays ahead of the caps, without changing saved pad dimensions or positions. Installed-GPU visual acceptance remains pending.
- Keep unpinned Properties panels hidden during received cross-selection, including probe pin selections; pinned or already-visible panels keep updating. Explicit inspection remains available.
- Preserve Properties-panel scroll, section expansion, search text and keyboard focus when following highlighted-net instances between sheets, including intermediate redraws.
- Keep theme state synchronized across drawing panes, pop-ups and project controls. Entering a sheet clears object/group selections and preserves only a matching highlighted net.
- Add zoom, pan, Fit and draggable positioning to the miniature sheet tree, retaining its view during highlighting and maximize/restore.
- Reopen a closed sheet browser from search using “sheet tree”, “sheet browser”, “sheet navigator” or “minimap”. The command works without repository search reads and switches to the schematic when needed.
- Improve companion discovery across sibling folders and hierarchy recovery when optional folder metadata fails. Pinned browser-session discovery no longer requires a fresh root lookup. Partial sheet/model inventories can recover after 30 seconds instead of remaining cached for 30 minutes.
- Discover repository and model folders in bounded three-read waves, keeping the existing directory, byte, cancellation and browser-session access limits. Display 3D board geometry before model inventory finishes, then load validated component models and later diagnostics asynchronously.
- Stabilize unchanged comment refreshes, simplify split/unsplit controls, and improve hierarchy links and supported schematic graphics, text boxes and bounded embedded PNG previews, including off-page content.
- Make conversation headers, navigation and message metadata denser, with readable message bodies, compact timestamps, day separators and secondary actions in More. Retain open menus, draft caret and scroll during unchanged refreshes; add Enter-to-review with Shift+Enter newlines and IME-safe autocomplete.
- Rank mention suggestions by username and available display name; offer existing annotation tags without confusing numeric issue references or reading tags from a new remote service.
- Put user text and screenshots first in new GitHub/GitLab annotation posts, with design metadata collapsed below. Preserve legacy annotation readback, revision-bound location markers and provider-side prose edits.
- Smart-target context comments to saved parts, individual terminals and nets. Add Draw comment area to the context menu and Comments navigation bar for 2D drawings; keep exact pad/net commenting available in 3D.
- Use small, borderless add-comment glyphs beside Properties and BoM values, reserving a consistent action column with hover, keyboard focus and touch sizing.
- Reduce Fast DC drop setup to A/B copper clicks, detected same-net/layer contacts, starting voltage and load current or power. Reuse saved stackup, choose an initial mesh automatically, and keep manual contacts/material settings in secondary controls. Constant-power mode includes copper drop and rejects infeasible operating points; missing stackup data remains explicit.
- Add non-destructive Fast DC drop Pause/Resume for board navigation, reachable saved-pad choices, independent contact replacement, retained results on Close, result-layer switching and Back to results. Reveal invalid fields for correction; reset stale isolation on committed changes and hide overlays while the panel is closed.

- Rename Fast PI to Fast DC drop and run its contacts, setup and results directly in Layout or 3D. Keep accepted results across view switches; use saved copper-only 3D picking and layer-aware result surfaces that follow explode spacing. Complete solved cells are shown in 3D; partial boundary cells are omitted.

## Verification boundaries

Focused source regressions cover these changes. Complete release gates, package audits and final source identity must pass before publication. No new installed-extension, private/organization SSO, physical-phone or Firefox Android acceptance is claimed. Browser-session viewing still depends on access allowed by the repository website and browser policy; this update does not bypass those controls or add broad repository permissions. Full Altium viewer parity is not claimed.
