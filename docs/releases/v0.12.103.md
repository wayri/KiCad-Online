# KiCad Online 0.12.103 / Android 1.101

- The PCB layer picker has a distinct Overview preset for outer copper,
  silkscreen and the board outline. All shows every saved layer.
- Highlighted PCB routes draw above faint gray context in Dim mode.
  Drill cutouts remain visible and clearing the highlight restores normal colors.
- The sheet minimap uses compact cards and keeps siblings at the same level.
  Choosing a reused sheet from the tree or minimap opens its saved occurrence
  with the correct sheet context.
- Cross-selection resolves unnamed nets using their saved terminals and handles
  multi-unit parts. The receiving pane centers the match and shows the saved
  board side when it can identify one.
- Opening a drawing and resolving nets uses compact source records. Revision
  comparisons still compute full fingerprints when needed.
- The 3D renderer reuses the parsed board and shares identical copper
  geometry. Linked models use bounded geometry, texture and scene budgets.
  If a model exceeds those limits, the viewer reports it and keeps the saved
  footprint proxy available for inspection.
- Saved KiCad simulation workbooks open with analysis tabs and interactive plots
  when matching results are available.
- GitLab review replies retain the verified issue discussion when posting.
- About and Settings show an alert when the browser reports a pending extension
  update. Check for updates is available in Settings and in the extension’s
  toolbar right-click menu on supported browsers.

The Safari GitHub download contains the Web Extension and an Xcode conversion
helper for macOS. Store approvals and Android distribution are tracked separately.

Browser checks exercised linked 3D selection on KERO and IRCA at desktop size
and in a 340 px iframe. IRCA retained 50 modeled components in both runs.
Its 3V3 highlight omitted the saved custom pad contours on JP5 and JP6.

A local run of the 44 MB Marble board showed 12 copper layers and 1,006 parts
in the narrow iframe. It took 8.1 s to open in this run. Sampled JavaScript
heap reached about 972 MB with GND selected, excluding GPU and whole-tab memory.
That highlight omitted 48 pad outlines and hit a separate saved-zone limit.
