# KiCad Online 0.12.104 / Android 1.102

- Large boards retain fewer temporary coordinates during parsing and 3D
  preparation. Saved zone fills use compact typed buffers shared with the main
  net highlight and the linked probe.
- Legacy pad IDs preserve saved oval drill dimensions, including pads with the
  same pin number. Supported asymmetric custom pads keep their saved copper
  contours and mirrored placements.
- The PCB layer picker has a separate Overview preset. Net highlighting leaves
  surrounding copper faint and gives the selected routes priority.
- Cross-selection centers matching parts and nets and uses the saved board side
  when available. The sheet minimap keeps siblings at the same level and opens
  the saved occurrence of a reused sheet.
- Saved KiCad simulation workbooks open with analysis tabs and interactive plots
  when matching results are available. GitLab replies retain their selected
  issue discussion.
- About and Settings show pending browser updates when reported by the browser.
  Check for updates is available in Settings and the toolbar icon's right-click
  menu on supported browsers.

Browser verification used the 44 MB public Marble board with 12 copper layers.
All 139 copper contours rendered. The four J10 oval slots retained their saved
drill dimensions, and both the main view and shared probe highlighted the same
31 GND fills with zero selected primitive omissions. IRCA's 3V3 selection also
retained its custom jumper copper.

In one Chromium test of the 340 px embed, sampled JavaScript heap reached
473 MB during selection and clearing with the shared probe, compared with
1,527 MB on the previous candidate. These samples cover JavaScript heap.
Physical-device performance and installed-store acceptance require separate
checks.

The Safari ZIP contains a Web Extension and an Xcode conversion helper. The
Android APK uses the development signing identity. Store versions and approval
states are tracked separately.
