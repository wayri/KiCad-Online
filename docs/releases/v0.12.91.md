# KiCad Online 0.12.91 / Android 1.93

Local release candidate preparation. This version has not been published or
uploaded to GitHub, extension stores, the VS Code Marketplace, or Google Play.

- Add a shared, read-only comparison workspace for saved drawings, project
  folders, text and CSV BoMs. Inspect before/after values across BoM, text,
  properties, schematic, layout and 3D views; filter changes and export deltas.
- Load selected repository revisions from an authorized project viewer. GitHub
  branch discovery and commit-parent history use the matching open repository
  tab's website session without requiring broader repository OAuth/API access.
- Show the first website branch window with an explicit partial-list warning.
  Read verified parent links for the initial commit window so actual branch and
  merge relationships can be displayed. Unavailable parent metadata remains
  unknown; feed order is never substituted for ancestry.

## Verification and limits

Local candidate verification: all 2,440 JavaScript checks passed. The Python gate has 149 passing checks and one Windows symbolic-link privilege skip; the corrected installation-metadata check passed on rerun. Chromium, Firefox and VSIX inventories match their source bytes. Android offline assemble, lint and bundle passed with 432 viewer assets verified, 19 lint warnings and no errors.
The GitHub history boundary passed 177 focused JavaScript tests during development.
Fresh production-viewer browser checks cover controlled value edits in the public PIC Programmer schematic/layout/3D and a CSV derived from the public HP34401a iBOM demo. Both drawing panes highlight the changed object; disabling highlights clears it. These are local-import tests, not two upstream design revisions.

Public GitHub branch and single-parent payloads were observed on
`wayri/KiCad-Online`; merge/root/failure cases are synthetic fixtures. These checks
do not establish installed-extension or physical-device acceptance.

Branch discovery currently reads one page of up to 20 website entries. History
uses the initial feed window of up to 30 commits, with bounded parent-page reads;
older history, unlisted branches and unavailable parents remain explicit limits.
The 3D comparison reports saved placement, side, model-reference and transform
changes. It does not compute Boolean differences between model meshes. Drawing
highlights and text comparisons retain their stated size limits. Repository comparison imports drawing sources without STEP/WRL assets; import complete project folders to include model geometry.

Altium beta remains separate and excluded. The intended Android deliverables are
a development-signed, non-debuggable APK and an unsigned AAB; the AAB is not ready
for Google Play upload. Safari remains a development conversion package requiring
macOS signing and runtime verification. No new device installation is claimed.
