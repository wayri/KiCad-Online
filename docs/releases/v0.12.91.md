# KiCad Online 0.12.91 / Android 1.93

Preview release of the latest source fixes. GitHub publication and platform-store submissions are separate steps.

- Add a dedicated **History** tab with branch lanes, searchable commit cards, Base/Head selection and visual comparison of CSV BoMs, text, properties, schematics, PCB layouts and saved 3D placements.
- Resolve explicit commit and pull-request links through the matching open repository website session. Find pull requests and commits inside the viewer; show partial history and unknown ancestry explicitly.
- Add a top-bar **BoM** browser with ranked CSV/TSV discovery, project-name matching and spelling variants. Multiple matches require a choice. Keep filters when switching tabs and provide Back to project and the drawing-linked BoM table. Standalone saved-file choices navigate to their exact source scope rather than widening file access.
- Draw sheet hierarchy with a shared parent rail and distinct child arrows. Fit the miniature tree to its floating box and separate hierarchy paths from dashed net guides.
- Load ordinary issue conversations and drawing annotations at project startup. Permit public issue readback without website login metadata while retaining sign-in and destination checks for posting. Preserve successful marker reads when the conversation catalog fails and show refresh errors.
- Recover a stale repository reader only in the exact previously invoked website tab. Preserve browser-session-only file reads and report specific reader failures rather than treating every failure as an SSO problem.
- Add Back navigation from comment options and move keyboard/navigation help into a toolbar popup.

## Verification and limits

Current source has passed focused viewer, transport, comment and hierarchy regression checks. Codex-browser checks on the public KERO encoder revision 45acf0a327c1f387e9fb1024638c3fbd06870ddc loaded its 79-part CSV BoM, checked filtering and return navigation, retained filters across tab switches, opened the drawing-linked BoM and inspected the six-sheet overview. These checks used locally buffered saved source.

The current source gate passed all 2,490 JavaScript checks and 149 Python checks, with one Windows symbolic-link privilege skip. The temporary-path separator mismatch from the first JavaScript run was corrected in the test environment; the full JavaScript rerun passed without test changes. Exact package inventories, source bytes, Android payloads and checksums are audited during packaging and recorded in the release manifest. Earlier local 0.12.91 packages are superseded and are not used for this publication.

Live installed-Chrome KERO issue reverse sync and private-repository SSO acceptance remain unverified. The local gallery intentionally disables remote comment loading. Reader recovery cannot sign in, bypass organization policy or grant access the website user does not have. Website issue catalogs and annotation discovery retain their bounded-window limits.

Git history uses the website's initial branch/commit windows; missing branches or parents are reported. 3D comparison highlights saved placement, side, model-reference and transform changes, not Boolean differences between meshes. Standalone CSV BoMs contain no board geometry unless supplied by their import format.

Altium beta is excluded. Android APK is development-signed and non-debuggable; the unsigned AAB is not ready for Google Play. Firefox desktop/Android and Safari installed-runtime acceptance are separate from package validation. No new store submission or phone installation is claimed.
