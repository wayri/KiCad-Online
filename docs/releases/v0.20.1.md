This focused browser update merges the redundant Open in KiCad control into Download.
The popup offers the complete repository ZIP, selected KiCad sources, searchable
vector PDFs for all or selected drawings, and current-drawing PNG export. Saving
never launches desktop KiCad. Incomplete inventories and oversized exports fail
explicitly instead of silently omitting drawings.

PDFs embed searchable Unicode text, saved component properties, net links, page
bookmarks and resolved sheet navigation. The bundled PDF viewer supports safe
click/right-click property inspection without executing PDF JavaScript. Other PDF
readers vary in property-menu support. Firefox retains its native PDF viewer;
its search, links and property behavior follow that native viewer. These are browser-rendered saved drawings,
not native KiCad CLI plots; unsupported renderings and net-class limitations are
reported. Whole-project ZIP is currently for remote repositories.

More tools shows the original Assembly, Rules and Reports actions once each.
Calculators remains under Engineering tools. Distinct table, overlay, statistics
and editing workflows are retained. The release preserves 0.20.0's newer renderer,
project navigation, memory and browser-package optimizations.

No new dependencies, fonts, native executables or browser permissions are required.
Browser packages and their hashes are verified before submission. Store review
and availability are separate from GitHub release publication.
