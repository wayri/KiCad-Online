# KiCad Online 0.20.2

- Select schematic rule areas and directive labels in the drawing. The inspector shows saved component classes and can highlight nets assigned to a class, with provenance for directives resolved from the loaded sheet.
- Follow component hover between the paired 2D drawing and bill of materials. Hover previews use amber and clear when the pointer leaves.
- Load only the embedded 3D model payloads referenced by the board. PCB rendering continues to use the compact saved copper representation.
- Browse saved simulation results by source. Open KiCad simulation workbooks, inspect saved traces, and link compatible results to an open drawing for cross-probing. See the [simulation walkthrough](../SIMULATION-WALKTHROUGH.md).
- Browse projects and standalone drawings by repository folder, with a project filter and paging.

The class inspector displays saved assignments it can resolve from loaded files. It does not evaluate custom PCB design rules or expand schematic bus assignments.
