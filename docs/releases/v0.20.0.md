# KiCad Online 0.20.0 / Android 1.104

## Viewer and navigation

- Project search starts when the project opens, keeps its index across views, and limits results to the open KiCad project and its related files. Part results focus the loaded drawing.
- Schematic net highlights follow saved connections across sheet levels and repeated instances. The minimap uses gold for the active sheet and amber for connected sheets. Press M to toggle it or press M twice quickly to maximize or restore it.
- History loads when the drawing opens. Its compact chart connects each commit node to its card, with one branch selector, an animated refresh control, and icon and context actions. The search field filters loaded history and opens repository URLs, commit SHAs, or GitHub pull requests.
- Drawing export opens in a compact panel over the current view. View options groups display, objects, assembly, and highlights. Overflow and context menus use consistent control spacing.
- All Sheets arranges drawings from the root down by depth. Rounded branches show saved hierarchy. Highlighted nets use curved arrows that follow saved signal direction where it is clear and flow outward from the selected point when it is ambiguous.
- PCB net hover uses each copper layer’s display color and respects layer visibility.
- Probe insets use compact icon controls and expand on demand. A broken link leaves a floating view that can reconnect after a matching selection in either the inset or the main drawing. Camera rotation keeps the inset’s viewport fixed.
- Drawing overlays wait for valid coordinates when a pane is collapsed. Incomplete repository discovery remains visible with a retry option.

## Large boards

- The viewer transfers saved copper-fill coordinates in compact buffers. Comparison retains the original saved source representation. Drawing and 3D views preserve saved contour coordinates and ordering.
- Selected geometry stays visible while large-board pan and zoom previews reduce background detail. 3D reduces repeated WebGL checks and defers new silkscreen detail while the camera moves.
- A local Marble import comparison retained the same 205,702 primitives, 122 saved-fill contours, 1,374 nets, and 46,310 net members. In that run, retained Node heap plus ArrayBuffers fell from 416 MiB to 289 MiB. Browser and GPU memory depend on the view and device.

The shared engine changes adapt KiCad WebView commits `d366fdc`, `64b8dc3`, `bb669c0`, and `8bf4f3e`.

## Android updates

The Android 1.104 development APK uses the same signing certificate as the published 1.102 APK. The 1.103 APK published by GitHub Actions uses a different certificate, so Android rejects an in-place update from that build. Follow the [installation guide](../INSTALL.md) to preserve projects and review state before changing installations.
