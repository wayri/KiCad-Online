# KiCad Online 0.20.3

- Toggle comment markers from the drawing toolbar. Published comments and the conversation remain available while drawing markers are hidden.
- Reply to existing GitHub issues from the viewer. If GitHub's page has no reply composer, the extension can use the connected matching GitHub account after checking permissions and repository policy. Unconfirmed writes keep their draft and require readback before another send.
- Find projects and standalone drawings by name and folder from the repository chooser. When the website listing is incomplete, the browser extension can read pinned GitHub tree metadata without downloading drawings or repository archives. Unscanned folders remain browseable.
- Focus and show or hide PCB layers in a compact picker. Press L to open it, brackets to cycle copper layers and Shift+L to switch between highlighting and isolation.
- Preserve board detail while panning dense layouts. In 3D, update probe windows when linked models arrive and reduce copper depth artifacts near overlapping surfaces.
- Open saved EMerge GUI results, Touchstone 1.x networks, and Quick EMerge plugin results from the Simulation library.

Android builds from this release use application version 1.105.
