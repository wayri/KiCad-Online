# KiCad Online 0.12.102 / Android 1.100

Cross-platform preview release. Store review and approval are tracked separately.

## Changes

- Schematic rendering selects saved embedded `lib_name` overrides, improves
  hierarchical sheet-pin markers and graphic text, and coalesces coincident
  pin-number labels without removing electrical pins. Saved source coordinates
  and connectivity remain intact.
- Text variables resolve within saved object and sheet-instance scopes. Text
  links support safe web destinations and internal sheet navigation. Bitmap
  handling accepts supported PNG and BMP payloads, including PNG trailing data.
- The sheet explorer presents repeated instances as readable rows. The minimap
  and all-sheet canvas share compact hierarchy positions and stable branch
  colors, with faint hierarchy links and more clearance around routed links.
  Selected net maps refresh connectivity after drawings load.
- Comment controls use a simpler placement toolbar, severity bubbles and
  corrected pane/capture offsets. Website-session sends retain the conversation
  context; manual export remains a separate action. Mention suggestions remain
  limited to people available through the selected transport.
- Metadata-only parsing reduces retained geometry in variable and hierarchy
  caches. Model discovery reuses parsed board data. These changes do not promise
  a particular whole-tab memory limit or browser loading time.
- Saved copper-fill rendering avoids stroking fill bridges. Bounded 3D zone
  allocation covers represented layers more fairly and reports omitted contours.
  Layer inspection isolates saved inner copper, then restores visibility choices.
- 3D silkscreen uses saved artwork. Expanded-board substrate materials restore
  correctly, close inspection is less restricted, and camera clipping adapts to
  the board bounds. Highlight strokes stay crisp without blur.
- Via annuli and barrels retain their gold appearance in 2D and 3D, including
  layer/accent highlight palettes. Other selected copper retains its layer colors.
- The project name appears in the workspace header and browser tab title.
  Schematic navigation excludes PCB files from the sheet selector.

## Validation and limits

The complete JavaScript gate ran 2,913 tests: 2,912 passed, no failures and one
environment skip. Python ran 167 tests with no failures and one Windows
symlink-privilege skip. Fresh native KiCad 10.0.6 exports confirmed all 48
reference/value field orientations across asymmetric-symbol and TestPoint
fixtures. The pictured private MOSFET placements were not reproduced.

The offline Android assemble/lint/bundle build passed with 19 lint warnings and
no errors. The release pipeline verifies embedded viewer bytes, versions and APK
signature before accepting its artifacts. The APK uses a development signing
identity; the AAB is unsigned and is not ready for Google Play.

Public KERO Encoder browser checks covered six-sheet navigation, Shift+grave
all-sheet switching, two-net map updates, minimap auto-restore, and assembled /
expanded 3D with a fitted phone-width viewport. These checks used local source
harnesses; they do not establish installed extension or physical-device acceptance.
KERO is the preferred demonstration project; IRCA is a fallback. WebView's active
demos and static exports now use pinned KERO sources and manufacturing exports.

Installed-browser comment round trips, large-board visual performance, and
physical-phone acceptance for this candidate remain unverified. Native stroke
font pixel equivalence and unsupported image formats are not claimed. Copper
budgets remain finite; omitted saved contours are reported rather than invented.
Store review and approval are separate from GitHub publication.
