Advanced server connection

Use an expiring token with access to your project. Project viewing uses the open website session and needs no token. Connected issue/discussion review actions need api; provider scopes may cover more than comments. Tokens use encrypted session storage and a background-memory key.

For server administrators: configure a non-confidential OAuth application with api scope and the exact browser redirect below. Publisher configuration is supplied with the build; users do not need to register their own application. Never enter a client secret.

Connection and browser checks

Project viewing needs access to github.com and raw.githubusercontent.com. Account and review actions can also need api.github.com; an API-only block does not mean that project viewing is blocked.

Run these read-only checks explicitly. They first inspect extension administrator controls, then contact public endpoints without project files, account credentials or cookies. They do not change site access or administrator policy.
